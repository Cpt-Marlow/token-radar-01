How the number is made

The model is one function of three figures the snapshot already carries, and no protocol name ever changes the answer.

  1. base = TVL × category multiple — the multiple is what a dollar of TVL has been worth in a franchise of that kind.
  2. growth = clamp(seven-day TVL change, −50% to +100%), and growth factor = 1 + growth × 0.4.
  3. maturity = 0.70 + min(days tracked, 1095) / 1095 × 0.30 — a protocol that has run longer without a token carries more of the record the value rests on.
  4. implied value = TVL × multiple × growth factor × maturity, rounded to whole dollars.
  5. The range re-runs the same arithmetic with the weekly change ten points weaker and stronger, so a row shows how much of its value rests on one week of data.

What this is not

  • Not a prediction that any protocol will issue a token. The model prices a token if the record stayed as it is.
  • Not make.fun’s forecast. The figure is this entry’s own claim, computed from the sealed snapshot.
  • Not a valuation of a live market price. Protocols that already trade are kept on a separate table.
  • Not advice to farm. Every plan spends real money on an unannounced outcome.
